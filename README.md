# 율포초 온라인 교무실 (리뉴얼)

| 구성 | 사용 기술 | 파일 |
|---|---|---|
| 프론트엔드 | GitHub Pages (HTML 한 장) | `index.html` |
| 백엔드 | Google Apps Script 웹 앱 | `gas/Code.gs` |
| 데이터베이스 | 기존 「율포초 온라인 교무실」 구글 시트 (Settings · MenuLinks · Apps) | 그대로 사용 |

기존 시트 구조를 바꾸지 않습니다. `업무명` 열을 **카테고리**로 사용하고, 새로 등록할 때 `유형 · 등록자 · 등록일` 열이 없으면 자동으로 추가됩니다.

## 1. 백엔드 배포 (5분)
1. [script.google.com](https://script.google.com) → 새 프로젝트 → `gas/Code.gs` 내용 붙여 넣기
2. `SHEET_ID`가 기존 시트 ID인지 확인 (기본값으로 들어가 있음)
3. 배포 → 새 배포 → 웹 앱
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자** (GitHub Pages에서 호출하려면 필요 · 데이터는 교직원 비밀번호 토큰으로 보호)
4. 처음 실행할 때 드라이브·시트·외부 요청 권한 승인
5. 발급된 `…/exec` 주소 복사

> 교직원 비밀번호는 Settings 시트의 `generalAdminPassword` 값을 사용합니다. 다른 키를 쓰고 있다면 `STAFF_PW_KEYS`를 고쳐 주세요.

## 2. 프론트엔드 배포
1. 이 저장소(`masterjppark/online`)의 `index.html`이 프론트엔드입니다
2. `index.html` 맨 아래 스크립트의 `var API_URL = '';` 에 1-5의 주소 입력
3. 저장소 Settings → Pages → Branch `main` / root → 저장
4. `https://masterjppark.github.io/online/` 로 접속

`API_URL`이 비어 있으면 **시안 모드**로 내장 데이터(기존 62건)를 보여 줍니다.

## 3. 주요 기능
- **부서 사이드 메뉴**: 13개 부서를 「업무 부서 / 교실·지원」 두 묶음으로, 부서별 페이지 수 표시. 묶음 제목을 누르면 접고 펼침(기본 펼침, 이 기기에 기억)
- **최고 관리자**: 왼쪽 아래 내 정보 → 🔐 최고 관리자 로그인 (Settings 시트의 `adminPassword`). 로그인하면 메뉴 맨 아래 **＋ 부서 추가**가 생깁니다
  - 부서 이름(중복 차단) · 메뉴 묶음(기존/새 묶음) · 아이콘 선택
  - 부서는 새 **Depts 시트**(부서명 · 묶음 · 아이콘 · 색 · 순서)에 저장됩니다. 처음 부서를 만들 때 기존 13개 부서와 함께 자동 생성되며, 순서·묶음은 시트에서 직접 고쳐도 됩니다
  - 서버에서도 관리자 토큰이 아니면 부서 생성을 거부합니다
  - **공지사항 수정**: 홈의 공지 띠 오른쪽 ✏️ → 그 자리에서 고치고 Enter(저장) / Esc(취소). 「띠 표시」를 끄면 교직원에게는 숨겨지고 관리자에게만 흐리게 보입니다. Settings 시트의 `noticeText`, `showNotice`에 저장됩니다
- **카테고리별 보기**: 부서 › 카테고리 › 링크 목록 (한 번에 한 카테고리만 펼침, 7개 이상이면 5개만 보이고 「더 보기」)
- **통합 검색**: `Ctrl K` 또는 `/` — 페이지명·담당자·부서·설명 검색, 부서 이동, 바로 등록
- **링크만 붙여 넣으면 등록**
  - 유형 자동 판별(시트·문서·슬라이드·설문·앱·영상·노션·AI·웹)
  - 제목 자동 불러오기: 드라이브 파일 이름 / 유튜브 영상 제목 / 웹페이지 제목
  - 담당자 자동 입력: 로그인 때 넣은 이름(이 기기에 저장) → 없으면 파일 소유자
  - 부서·카테고리는 최근 값과 기존 카테고리 목록을 자동 제안
- **중복 입력 방지**: `/edit`, `/view`, `?usp=sharing`, `youtu.be` ↔ `youtube.com` 처럼 주소가 달라도 같은 문서면 차단 (화면 + 서버 2중 확인)
- **즐겨찾기 · 최근 본 페이지**: 이 기기에 저장
- **상세 패널**: 설명·담당자·같은 카테고리 페이지, `J / K`로 이전·다음

## 4. 기존 데이터 점검 결과
- 같은 링크가 두 번 들어간 항목 2쌍: **003 통합위원회 운영 = 014 법정 의무 연수 기록장**, **017 = 018 자전거 안전 영상**. 014의 링크가 잘못 들어간 것으로 보입니다. 편집기에서 `checkDuplicates()`를 실행하면 목록을 다시 볼 수 있습니다.
- 001 「페이지 3」은 링크가 없는 예시 행입니다. 표시 여부를 FALSE로 바꾸면 숨겨집니다.
- 일부 설명(010 등)에 비밀번호 안내가 들어 있습니다. 화면에 그대로 노출되니 설명에서 빼고 담당자에게 따로 안내하는 것을 권합니다.
- 카테고리(`업무명` 열)는 대부분 비어 있어 시안에서 임시로 채웠습니다. 실제 시트에 같은 이름으로 넣으면 그대로 반영됩니다.
